# JUL-317: the first start-machine practice run

Ran 2 November 2026 against `node scripts/start-machine.mjs`, the command that takes a card from
start to Complete.

## What the run did

- The build stage opened branch `docs/jul-317-practice-note` and pull request #422, carrying the
  scorecard measured from Mastra Code's records.
- The review stage judged the card's first criterion PASS: `docs/practice/README.md` lists JUL-317
  and the date it ran.
- The review stage judged the card's second criterion FAIL: JUL-317 was in Implementation with no
  comments, so it did not show Complete with a comment naming the change that landed.

## The fault this run found

The second criterion cannot be settled by the review that guards the merge, so the command has no
way to satisfy it.

- `scripts/start-machine.mjs:163` runs the review loop, and `scripts/start-machine.mjs:171` runs the
  merge stage after it.
- `machine/merge/land.mjs:227` posts the completion comment and `machine/merge/land.mjs:229` moves
  the card to Complete, and that is the only code in this repository that moves a card there.
- So a criterion naming the card's own completion is false at every review, while the review must
  pass before the stage that makes it true can run.

## What this run changes

Nothing in the machine yet. A card whose criteria name the machine's later steps burns both reviews
and stops, and this run is the evidence for that. The next move is to keep a card's criteria
observable from the pull request the review is given, or to move the completion step in front of the
review, and the practice notes need a line saying which.
