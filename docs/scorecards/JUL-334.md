   > ## Q4 — Do an agent step's records nest under the workflow run, and do they carry the thread id?

   >
   > **Thread id: no, not automatically.** (measured) The nested proof's `metric_events` rows all have `threadId` and `resourceId` **null**, and no span attribute contains a thread id. So a workflow step must both pass a memory thread **and** carry the id; nesting alone does not produce it.
   >
