## Verification entrypoints

- `npm run test:jul-243` runs deterministic state, persistence, boundary, logging, real local Mastra, and phone UI checks.
- `npm run test:jul-243:contracts` explicitly runs real installed Codex and CommandCode contracts. It includes two concurrent CommandCode processes, terminal results, a missing executable, and premature process termination. It is separate from the ordinary package suite because it uses signed-in providers.
- `npm run proof:jul-243 -- /absolute/evidence/directory` runs only after the round's Gemini review passes. It launches a distinct candidate dashboard process, records the SHA/digest and native versions/schema hash, holds three actual providers, captures both statuses, releases the holds, then starts a fresh dashboard process and reads retained events and traces. `JULIA_REVIEW_ROUND` is 1 or 2; no third round is allowed.

Codex loss of connection is explicitly disconnected until an official reconciliation. Unsupported CommandCode variants remain unknown; completed text never supplies a fabricated outcome. The projection is Julia policy (15 minutes or three consecutive identical explicit failures), not a claimed vendor feature.
