# 0019 The running card's remaining questions

Todd, 28 Oct 2026, going through the running card's gaps G3 to G8.

* **Current step.** The line reads "Current step:" (not "Doing now"), naming the checklist step marked working, so the line and the checklist never disagree, plus the time since the build's last activity.
* **Context fill and handoffs.** Each agent has its own line with its context fill and compactions; the card shows its handoff count. Context fill matters because condensing memory only slows its growth; it does not stop an agent drifting as its context grows (Todd). The runner enforces handoffs: an agent over 50% full is handed off to a fresh chat at its next break (when it finishes the step it is on); at 60% the runner pauses it and hands off right away. Rejected: a Hand off button for Todd (let the runner do it), and taking context fill off the running card.
* **Stuck and waiting.** Stuck: rose pulsing pill and icon, and the Current step line adds "no activity for 7 min". Waiting on you: steady amber pill, the build's question shown on the card, and an Answer box that sends the answer straight to the build.
* **Skipped steps.** Tapping "why?" opens the reason in a line under the step; tapping again closes it.
* **Stop.** Stays rose with its icon and word ("red colours tend to indicate a problem whether we decide it or not"), and asks "Stop this build? The work is kept." before ending it. This replaces 0008's "button colour carries no meaning": rose means a problem or a destructive action (Stuck, Stop); other button colours carry no meaning.
* **Step names.** The checklist shows the playbook's own step text; where a step's text is jargon, the playbook gets a plain-word label for that step, so the checklist and the dashboard use the same words.
