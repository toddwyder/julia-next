# 0021 A weekly sweep keeps the model list and prices

Todd, 28 Oct 2026, reviewing pstack's plan for the Start card. A weekly agent sweep checks which models Todd's accounts offer, adds new ones, retires ones that are gone, and records every model's price from the provider's own pricing page with its date. The Start screen lists only what the sweep has saved, so every model it shows has a price; a brand-new model can take up to a week to appear. The sweep reads its list of accounts (today Claude subscription, ChatGPT plan, CommandCode) from one place, so adding an account later is a change to that list, not a rebuild. Adding a subscription or model from the dashboard is separate work in the Dashboard project's Backlog. Refines 0015. Rejected: showing "No published price" for a model the public list lacks (DeepSeek through CommandCode); refreshing the list hourly from the public catalogue alone.
