# 0010 One spec per screen

Todd, 27 Oct 2026, after the single dashboard spec came out too thin to build from without guessing. Each screen gets its own spec, small enough to carry every detail of that screen: each thing on it, what it means, where its data comes from, and Todd's comments from the design chats. Seven specs: board, running card, stopped card, Needs you, Start, Decision support, card page. The part that starts, watches and stops builds goes in the Start screen's spec, because pressing Start and watching a card run proves it; that spec is built first. Each new thing the build must record goes in the spec of the screen that shows it (for example, each request's role with Decision support). The first issue saved for the dashboard becomes the project's overview or is replaced. Rejected: one spec for the whole dashboard.
