# 0012 Panel models are chips you add and remove

Todd, 27 Oct 2026, reviewing the Start screen's gaps (G3). With the Panels group open, each panel shows its models as chips, each with an ×, plus a "+ Add" chip that opens the same model list as 0011. The number of chips is how many helpers run in that panel. A panel keeps at least one model.
