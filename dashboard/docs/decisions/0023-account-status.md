# 0023 Account status is read fresh when Start opens

30 Oct 2026, JUL-290. The Start screen shows Claude and ChatGPT 5-hour and weekly use, CommandCode monthly use, and a separate bought-credit balance. Each number sits beside its quota or says what is left. A missing number has a named unreadable state, never a zero. Nearly exhausted accounts warn in the account section and under their name in the model picker. These rows are information, not a gate, and remain visible without a model sweep.

A plain-Node runner reads credentials and calls the providers outside the Next bundle. Both subscription signs-in are read through Mastra Code's SDK AuthStorage, `getOAuthCredential('anthropic')` and `getOAuthCredential('openai-codex')`. The dashboard has no refresh implementation, its own expiry check, or its own auth-file parser, and never writes, repairs, or deletes that file. A read of a valid token writes nothing, proved on 30 October with a copy of the real auth file whose SHA-256 stayed `7935e27d69387b37` across construction and both reads. CommandCode uses the server's API key. Errors carry fixed problem codes, not provider text or credentials.

There is no cache and no estimate. Every Start open reads each provider with no-store requests and an eight-second request timeout. A failed account does not hide another account. A failed CommandCode monthly read does not hide a readable bought-credit balance.

CommandCode's 5-hour and weekly windows stay off this screen. Their caps look like dollar amounts, but the payload does not name the unit. Showing a comparison we cannot label would be a guess.

The CommandCode monthly row shows two provider numbers and no total. `usage/summary.totalMonthlyCredits` is what the month has used and `billing/credits.credits.monthlyCredits` is what is left of the month's credit. The provider publishes no monthly allowance, so the screen never adds them up: eighteen billing, plan and account routes were tried on 30 October and every one answered 404, and no response field carries a cap. The row therefore reads `This month: $24.27 used. $45.88 of credit left. Renews 22 Nov.` and takes its level only from the provider's own signals, `credits.belowThreshold` for nearly out and a zero balance for out. A comparison the provider never sent would be our arithmetic, not its number.
