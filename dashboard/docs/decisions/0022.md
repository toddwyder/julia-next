# 0022 The dashboard is its own app on the server, observed and kept running

Todd, 28 Oct 2026, reviewing pstack's plan for the Start card. The dashboard is its own app in its own folder in julia-next, run only on the server, never part of Julia's Vercel app; its decision records and glossary live in that folder, apart from Julia's. It runs as a server service that starts on boot and restarts after a crash, always from main; a merge to main updates it only after running builds finish (the old machine once lost a running build to a merge). Every dashboard build keeps cost recording on, so its scorecard has cost per model. Errors go to Sentry and Start, Stop, build state changes and price sweeps are logged to Axiom, each in the dashboard's own project and dataset; if the dashboard goes down, Todd gets a Linear notification. Rejected: a route inside Julia's app hidden by a switch; turning cost recording off for dashboard builds because only one Mastra Code process can record at a time (that limit is to be solved, not worked around).
