# Issue #144 — Clean up the leftovers the audit found

## Goal

Leave one usable copy of each active project skill, remove the three retired Julia graph roles and their test pins, align agent instructions with the stock GitHub/Factory route and ADR 0009, and shut down/remove the old graph-era services on the OVH host without disturbing Factory, its wait alerts, or CI. Prove skill discovery in both Factory and Claude Code and record the actual server changes and results in the change log. A repository-only deletion is not completion of the live-service criterion.

## Scope

- In: the mirrored `.agents/skills/` and `.claude/skills/` trees; active references to moved skills, `scripts/agent-docs.test.mjs` and graph-era role tests; `CLAUDE.md`, `AGENTS.md`, current-route links in `docs/agents/work-execution.md` and Factory skill overrides; old graph/watchdog/Orca/controller/queue/relay systemd assets and their obsolete checks as warranted by live inventory; `docs/agents/server-runbook.md` and `docs/agents/factory-platform-auth-change-log.md`.
- Out: altering Mastra/Factory packages or adding a skill-root patch; rewriting archived graph implementation or historical research solely to erase its history; removing the current Factory service, #148 `julia-factory-wait-alerts` timer, GitHub CI runner, or its required checks; deleting credentials or unrelated host data. Stop and obtain Todd's approval, with the gap and official docs, before any unapproved workaround to stock products.
- Existing tools checked: Factory 0.17.2's own local skill discovery scans both roots (`ops/factory/README.md`); Claude Code documents project skills at `.claude/skills/` ([Claude Code skills](https://code.claude.com/docs/en/skills)); Factory's project-local `factory-skills` overrides already implement plan/review customization (`ops/factory/README.md`). Neither requires a new loader or custom daemon. Factory's Work/Review boards and GitHub approvals already replace the old Linear checklist, Orca controller, and publisher-led card merge ([Factory guide](https://factory.mastra.ai/); `docs/adr/0009-mastra-factory.md`). Before implementing, post this framework map on #144 as the project's framework-first rule requires.

## Risks

- Claude Code has a documented `.claude/skills` project path; a `.agents`-only migration or duplicate-preserving symlinks would break one of the two loaders. Recheck both in fresh sessions before claiming success.
- Graph-era tests/scripts may reference deleted role files; inventory live entry points first and retire only obsolete callers, retaining valid current-route tests.
- A systemd user unit may still run despite removal from the repo; inventory and stop on the host before claiming removal, using `orchestrator-svc`'s user bus. A service name resembling a graph watchdog must not cause deletion of Factory's #148 wait-alert timer.
- The sandbox may lack SSH/systemd or credentials; never infer live unit state from the runbook. Mark live acceptance pending until operator-verified evidence exists.
